# Академія Віки (ClayAway Academy)

Навчальний сайт для Віки — організаторки турів ClayAway і перекладачки — з термінології clay shooting.
Окремий проєкт; виділений 05.10.2026 з репозиторію ClayAway (`fenix-112323/clayaway`, папка `docs/academy`) з історією.

## Що тут
- `index.html` — застосунок: мапа місій, історія, терміни, квіз, «Переклади тренера», глосарій, XP і рівні, UA/EN.
- `data/<module>.js` — 5 місій: sporting, compak, guns, technique, organizer. Формат: `data/SCHEMA.md`.
- `data/check.mjs` — перевірка даних (дублікати id, биті посилання, мова): `cd data && bun check.mjs`.
- `data/export.mjs` — збирає `glossary.json` (чернетка глосарію): `cd data && bun export.mjs`.
- Сайт статичний; GitHub Pages з кореня репозиторію (`main` / `/ (root)`). Індексується: статичний глосарій `glossary/` (bun scripts/build_seo.mjs), sitemap, Course/DefinedTerm.
- Для програмістів: DEVELOPERS.md. Усе називаємо проєктом; коментарі в коді — для команди ClayArena.

## Правила
- Персоналізація під Віку: звертання «Віко», знак **Ю** (паличка — ствол, «О» — помаранчева тарілочка), дизайн ClayArena (темний, смарагдовий акцент).
- Терміни завжди англійською; пояснення українською та англійською. Література українська, без суржику.
- **Російську мову не використовуємо**; Росію не згадуємо ніколи (ні слова, ні прапора).
- Терміни з `verify: true` звіряти з офіційними регламентами FITASC (довідник правил живе в проєкті ClayAway: `docs/rules/`).
- Посилання на FITASC — `rel="nofollow noopener noreferrer"`; текст регламентів не копіюємо.
- Перегляд локально: `python -m http.server 8793 --bind 127.0.0.1` у корені проєкту.
