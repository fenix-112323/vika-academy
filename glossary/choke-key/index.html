Choke key

Також: Choke wrench, Choke spanner

Що це

Невеликий інструмент для вкручування й викручування чоків.

A small tool for screwing choke tubes in and out.

Детально

Ключ для чоків входить у пази чи вирізи всередині насадки. Кожна система чоків потребує свого ключа; невідповідний може пошкодити насадку або різьбу ствола. Багато стрільців носять ключ у сумці для патронів або на шнурку. Насадки затягують лише з помірним зусиллям руки, без надмірної сили, а трохи спеціального мастила на різьбі не дає їм «прикипіти». Загублений ключ для чоків у турі — класична проблема; зазвичай допоможе крамниця стрільбища або інший стрілець із такою самою системою.

A choke key fits the slots or notches inside the choke tube. Each choke system needs its own key; a wrong one can damage the tube or the barrel threads. Many shooters carry it in the cartridge pouch or on a lanyard. Tubes are tightened by hand-firmness only, never with extra force, and a little choke grease on the thread keeps them from seizing. Losing the choke key on a tour is a classic problem — the ground shop or another shooter with the same system can usually help.

Як кажуть українською

«ключ для чоків», «ключик»

Як це звучить на стенді

“Has anyone got a Beretta choke key? Mine is back at the hotel.”

Ні в кого немає ключа для чоків Beretta? Мій залишився в готелі.

Порада перекладачеві

Не плутайте з «top lever», який стрільці теж називають «ключем».
