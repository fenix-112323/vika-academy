Детально

Стартовий протокол поєднує скводи зі стартовим часом і, у спортингу, часто з трасою чи позицією, з якої кожен сквод починає. На багатоденних змаганнях — окремо на кожен день. Для організатора це головний інструмент планування: трансфер, сніданок і обід будуються саме довкола нього.

The start list combines squads with start times and, in sporting, often the layout or stand where each squad begins. On multi-day events it shows each day separately. It is the organizer's main planning tool: transfers, breakfast and lunch are all built around it.

Як кажуть українською

«стартовий протокол», «стартовий лист», «розклад».
